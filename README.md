# শাহিন সরকার | রেজুমে

বাংলা ভাষায় তৈরি একটি ওয়ানপেজ রেজুমে/পোর্টফোলিও ওয়েবসাইট। Next.js এবং Tailwind CSS দিয়ে তৈরি, Vercel এ ডিপ্লয় করার জন্য প্রস্তুত।

## কনটেন্ট এডিট করবেন যেভাবে

এখনো না দেওয়া তথ্যের জায়গায় "পরে যোগ করা হবে" লেখা আছে, সব একই জায়গায় রাখা:

- `src/data/resume.ts`: প্রোফাইলের তথ্য, কুইক ফ্যাক্টস এবং প্রতিটি সেকশনের, যেমন ব্যক্তিগত তথ্য, শিক্ষা, অভিজ্ঞতা, দক্ষতা, লেবেল ও মান এখানে।

এই ফাইলে পরিবর্তন আনলেই পুরো সাইট আপডেট হয়ে যাবে, আলাদা কম্পোনেন্ট এডিট করার দরকার নেই।

## লোকাল ডেভেলপমেন্ট

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন।

## বিল্ড

```bash
npm run build
```

## ডিপ্লয়

Vercel এ রিপোজিটরি ইমপোর্ট করলেই ফ্রেমওয়ার্ক অটো-ডিটেক্ট হয়ে ডিপ্লয় হয়ে যাবে, কোনো এক্সট্রা কনফিগারেশন লাগবে না।

## PDF নতুন করে তৈরি করা

"PDF ডাউনলোড" বাটনটি `public/shahin-sarker-biodata.pdf` ফাইলটা সরাসরি ডাউনলোড করায়। এটা একটাই লম্বা পেজের আসল টেক্সট-ভিত্তিক ভেক্টর PDF, স্ক্রিনশট নয়, তাই টেবিল কোথাও পেজ-ব্রেকে কাটা পড়ে না এবং যেকোনো সাইজে জুম করলেও লেখা পরিষ্কার থাকে।

`src/data/resume.ts` এ কনটেন্ট বদলানোর পর এই PDF নতুন করে তৈরি করতে, লোকালি:

```bash
npm i -D playwright && npx playwright install chromium
npm run generate:pdf
```

তারপর তৈরি হওয়া `public/shahin-sarker-biodata.pdf` ফাইলটা কমিট ও পুশ করে দিন। এটা ইচ্ছা করেই Vercel বিল্ডের সময় অটো চলে না, কারণ বিল্ডের ভেতর ব্রাউজার চালানো Vercel-এ নির্ভরযোগ্য নয়, একবার পুরো ডিপ্লয়মেন্ট এই কারণে আটকে গিয়েছিল, তাই PDF জেনারেশনটা ইচ্ছাকৃতভাবে ম্যানুয়াল রাখা হয়েছে।
